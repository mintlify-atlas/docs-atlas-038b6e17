Veyra is a self-hosted developer infrastructure platform built for teams who need reliable application monitoring, Discord bot uptime tracking, and incident management without relying on third-party SaaS tools. It exposes a clean REST API that works from any language — TypeScript, Python, Go, Rust, and beyond.

## Get Up and Running

<Steps>
  <Step title="Create an account">
    Register at `https://api.strixhost.xyz/v1/auth/register` with your email and password to get started.
  </Step>
  <Step title="Create a project and API key">
    Set up a monitoring project and generate an API key — this key authenticates all telemetry calls.
  </Step>
  <Step title="Send your first event">
    POST a structured log event to `/v1/events` using your API key as the Bearer token.
  </Step>
  <Step title="Add heartbeat monitoring">
    Schedule a periodic ping to `/v1/heartbeats/:projectId` to track uptime across your services.
  </Step>
</Steps>

<Note>
  Veyra uses two authentication mechanisms: **JWT tokens** for account management (projects, keys) and **API keys** for telemetry (events, heartbeats, incidents). See the [Authentication guide](/authentication) for details.
</Note>
