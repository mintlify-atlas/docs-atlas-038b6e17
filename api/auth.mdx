---

These two endpoints bootstrap your Veyra account — register once to create your developer profile, then log in whenever you need a fresh JWT. That token is required for all account management operations, including creating projects and generating API keys.

---

## POST /v1/auth/register

Creates a new Veyra developer account.

### Request body

<ParamField body="email" type="string" required>
  Developer email address. Used as the unique identifier for your account.
</ParamField>

<ParamField body="password" type="string" required>
  Account password. A minimum of 8 characters is strongly recommended.
</ParamField>

### Example request

```bash
curl -X POST "https://api.strixhost.xyz/v1/auth/register" \
  -H "Content-Type: application/json" \
  -d '{"email": "dev@example.com", "password": "supersecure123"}'
```

### Response

<ResponseField name="id" type="string">
  Unique identifier for the newly created account.
</ResponseField>

<ResponseField name="email" type="string">
  The email address associated with the account.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 timestamp of when the account was created.
</ResponseField>

```json 201 Created
{
  "id": "usr_01j9xkq2v3f8n7p4r6t0",
  "email": "dev@example.com",
  "createdAt": "2025-01-15T10:32:00.000Z"
}
```

### Error responses

| Status | Description |
| ------ | ----------- |
| `400 Bad Request` | One or more required fields are missing or malformed. |
| `409 Conflict` | An account with this email address already exists. |

## POST /v1/auth/login

Authenticates an existing account with email and password, and returns a signed JWT token for use in subsequent API calls.

### Request body

<ParamField body="email" type="string" required>
  The email address registered to your Veyra account.
</ParamField>

<ParamField body="password" type="string" required>
  The password associated with your account.
</ParamField>

### Example request

<CodeGroup>

```bash cURL
curl -X POST "https://api.strixhost.xyz/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "dev@example.com", "password": "supersecure123"}'
```

```javascript JavaScript
const res = await fetch('https://api.strixhost.xyz/v1/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'dev@example.com', password: 'supersecure123' })
});
const { token } = await res.json();
// Store this token for subsequent API calls
```

</CodeGroup>

### Response

<ResponseField name="token" type="string">
  A signed JWT token. Pass this as a `Bearer` token in the `Authorization` header for all account management endpoints.
</ResponseField>

```json 200 OK
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJ1c3JfMDFqOXhrcTJ2M2Y4bjdwNHI2dDAiLCJpYXQiOjE3MDUzMTI3MjB9.abc123"
}
```

### Error responses

| Status | Description |
| ------ | ----------- |
| `401 Unauthorized` | The email or password is incorrect. |

<Warning>
  **Never expose your JWT in client-side code or commit it to version control.** Store it in an environment variable or a secure secrets manager. JWTs grant full access to your account — treat them with the same care as a password.
</Warning>
